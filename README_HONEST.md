# HD-MixNet — repository overview

HD-MixNet is a dual-branch CNN + Swin-Transformer segmentation network
for colonoscopy polyp segmentation, with explicit boundary supervision
(YOHO-style Edge-Detect / Boundary-Enhance blocks) and a Hausdorff-DT
auxiliary loss. The architecture and motivation are described in the
thesis; this README documents what the repository actually contains.

## Results reported in the thesis

On the Kvasir-SEG benchmark, under the model's own evaluation protocol:

| Metric | Value |
|---|---|
| Mean Dice | 0.896 |
| Mean HD95 | 9.8 px |
| Parameters | ~1.17 M (thesis figure; depends on the channel widths in `config.py`) |

These are the numbers that should be cited. Earlier versions of this
repository included guides claiming 94.5 % Dice / 89.5 % IoU as the
"expected" result of running the included training script; that was
aspirational, was never reproduced, and those documents have been removed
in favour of `docs/REVIEWER_RESPONSE.md` and `docs/REPRODUCIBILITY.md`.

Headline caveats taken directly from the thesis:

- HD95 is reported here as worse than several comparison methods. The
  thesis discusses why (Section 4.6): the baseline numbers are taken
  from different papers under different splits and resolutions, and a
  differentiable surrogate of the Hausdorff distance does not directly
  optimise the discrete 95th-percentile metric.
- Evaluation is on Kvasir-SEG only. Cross-dataset evaluation infrastructure
  is now provided (`cross_dataset_eval.py`) but the results table for
  CVC-ClinicDB / CVC-ColonDB / ETIS-Larib needs to be produced by running
  it.

## Repository layout

```
Models/
    hd_mixnet.py            # main model; supports ablation switches
    Components/
        res2net.py          # Res2Net bottleneck block
        swin_transformer.py # window/shifted-window attention blocks
        layers.py           # ConvBNAct, SE, fusion, ED/BE blocks
Utils/
    losses.py               # JointLoss + canonical Hausdorff-DT loss
    metrics.py              # Dice, IoU, HD95
    dataset.py              # KvasirDataset (works for any polyp dataset
                            # with images/ and masks/ subfolders)
    inference.py            # TTA, postprocessing, checkpoint loading
    transformers.py         # data augmentations
config.py                   # all hyperparameters; ablation switches
train.py                    # training + run_metadata.json + threshold modes
evaluate.py                 # evaluation + 95 % CI + optional FPS
cross_dataset_eval.py       # multi-dataset evaluation
run_ablations.py            # train every ablation variant
summarize_ablations.py      # aggregate ablation runs into a table
docs/
    REVIEWER_RESPONSE.md    # which change addresses which reviewer point
    REPRODUCIBILITY.md      # concrete hyperparameter table
    README_HONEST.md        # this file
```

## Quick start

```bash
# 1. Train
python train.py
# -> writes checkpoints/{best_dice_model.pth, best_hd_model.pth,
#                       run_metadata.json, metrics_history.json}

# 2. Evaluate (with 95 % confidence intervals and FPS)
python evaluate.py --path checkpoints/best_dice_model.pth --measure-speed

# 3. Cross-dataset evaluation (only datasets actually on disk are used)
python cross_dataset_eval.py --path checkpoints/best_dice_model.pth

# 4. Ablation matrix (10 variants x several seeds)
python run_ablations.py --epochs 50 --seeds 42 1337 2024
python summarize_ablations.py
# -> writes results/ablation_summary.{csv,md}
```

## Ablation switches in `config.py`

| Setting | Effect |
|---|---|
| `BRANCH_MODE = 'both'` | Default: dual CNN + Swin encoder |
| `BRANCH_MODE = 'cnn_only'` | Drops Swin branch entirely |
| `BRANCH_MODE = 'swin_only'` | Drops Res2Net branch entirely |
| `USE_BAMF = False` | Replaces Boundary-Aware Mix-Fusion with naive concat + 1×1 conv |
| `USE_EDGE_SUP = False` | Removes ED, BE, and the edge supervision head |
| `LAMBDA_HD = 0.0` | Disables the Hausdorff-DT loss term |
| `LAMBDA_BOUNDARY = 0.0` | Disables the boundary-dice loss term |
| `THRESHOLD_SELECTION = 'hd95'` | Selects validation threshold by HD95 instead of Dice |

`run_ablations.py` combines these to produce the variants listed in the
reviewer's report.

## Status

This is research code for an M.Tech thesis. It is not production-ready
software:

- The reported Dice/HD95 numbers come from one training run on Kvasir-SEG.
  Statistical robustness across seeds and across datasets is still to be
  generated by running the supplied scripts.
- Comparison with prior work in Table 4.1 of the thesis is *indicative*:
  baseline numbers come from the original papers and were not re-run
  under the same protocol.
- The Hausdorff-DT loss, as implemented before this patch, did not match
  the canonical Karimi & Salcudean formulation. It does now.
